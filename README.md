# Magnetic Field Helical Magnetic Trap

Parallel implementation(s) of a program for computing magnetic field in a helical magnetic trap.

## Implementations

- `fortran` - original sequential Fortran implementation.
- `cpp` - sequential C++ implementation.
- `openmp` - parallel OpenMP implementation for shared memory.
- `mpi` - parallel MPI implementation for distributed memory.

## Build & Install

With CMake or Qt.
